# TNC Fast Food Website

A modern, mobile-first website for **TNC Fast Food** — serving delicious Kotas, chicken, chips, wings, snacks and drinks.

## Live Features

- Fully responsive (mobile, tablet, desktop)
- Sticky WhatsApp order button on mobile
- Smooth scrolling navigation
- Hamburger menu on mobile
- Pre-filled WhatsApp ordering message
- Clean black / red / white design with green WhatsApp accents

## How to View Locally

1. Download / extract the folder
2. Open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge)

## How to Host (Free Options)

- **Netlify**: Drag & drop the folder at [netlify.com/drop](https://app.netlify.com/drop)
- **Vercel**: Import the folder
- **GitHub Pages**: Push to a repo and enable Pages
